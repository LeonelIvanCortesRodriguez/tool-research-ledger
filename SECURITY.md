# Security policy

This repository is a static research interface. Do not submit private documents, extracted financial rows, credentials, access tokens, customer data, or non-public audit evidence in an issue or pull request.

Report a suspected vulnerability privately to the repository maintainer once a public hosting account and security contact are configured. Until then, do not publish exploit details. Include the affected file, reproduction steps using public-safe data, and expected impact.

Catalog decisions are not security certifications. Validate a tool in an isolated environment before granting credentials, network access, browser state, or production data.
